
# Summer Ops

暑期 Linux 运维 Shell 脚本集合。

## 脚本说明

| 脚本 | 功能 |
|------|------|
| sys_inspect.sh | 系统巡检（CPU/内存/磁盘/用户/SSH安全） |
| check-logs.sh | 日志路径解析 |
| syscheck.sh | 系统检查 |
| menu.sh | 菜单分支示例 |
| countdown.sh | while循环倒计时 |
| greet.sh | 位置参数练习 |
| hello.sh | 第一个脚本 |
| loop.sh | for循环练习 |
| compare.sh | 条件判断 |
| check.sh | 文件测试 |
| debug-demo.sh | 调试技巧演示 |
